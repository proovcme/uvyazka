# Увязка

**Проверяемая база строительного проекта для настольных ИИ-клиентов.**

Увязка — набор MCP-инструментов и навыков для руководителей проектов и ГИПов.
Она связывает ПД и РД, показатели здания, объёмы, сметы и планирование
с исходными документами.

Пользователь работает в своём ИИ-клиенте. Увязка предоставляет инструменты
и сохраняет данные проекта между диалогами и приложениями.

## Возможности в разработке

- Реестр документов, ревизий и состава проекта.
- Показатели здания: ТЭП, помещения, площади, высоты, ТУ, мощности и расходы.
- Сверка наименований и количеств: проект → спецификация → ВОР → смета → поставка.
- Источник каждого числа и объяснение расхождений.
- Работы, ресурсы, зависимости и расчётный график строительства.
- Подготовка ПОС и ППР по проверенным исходным данным.
- Локальная панель показателей и несколько проектов в одной рабочей среде.

## Подключение

Основной интерфейс — локальный MCP. Первая целевая среда — Codex на Windows,
далее Claude Desktop и другие совместимые клиенты. Навыки и установка
адаптируются к конкретному приложению; совместимость проверяется отдельно.

Модель и диалог остаются в выбранном клиенте. Обязательного подключения
к API моделей или собственного сервера генерации у Увязки нет.
CAD/BIM, семантический поиск, локальные модели и прямые API — дополнительные интеграции.

## Принципы

- Каждое значение связано с источником и его версией.
- Пропуск, ошибка извлечения и проектное расхождение имеют разные статусы.
- Полнота обработки считается по документам и строкам, а не по ответу модели.
- Данные разных проектов разделяются; исходные документы сохраняются.
- Общая база проекта используется всеми клиентами и панелью.

## Статус

Ранняя разработка. В репозитории пока описание продукта и архитектуры;
готового устанавливаемого пакета нет. Перечень выше задаёт направление разработки.
