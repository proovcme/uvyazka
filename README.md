**Проверяемая память строительного проекта для РП и ГИПов.**

Увязка сохраняет документы, числа, их источники и результаты сопоставления
между диалогами. Модель работает в вашем ИИ-клиенте, а локальные MCP-инструменты
и навыки помогают читать проект, находить расхождения и готовить основания
для графика, ПОС и ППР.

## От документа к проверяемому числу

| Задача | Что даёт Увязка |
|---|---|
| Продолжить работу с проектом | Локальную память с версиями и поиском по сохранённому тексту |
| Понять, откуда значение | Исходное написание, единицу, основание и адрес в документе |
| Сопоставить количества | Сравнение при одинаковом смысле и единицах, вопросы при расхождении |
| Исправить чтение | Новую ревизию с причиной, сохранением истории и пересмотром зависимостей |
| Вести несколько объектов | Отдельные базы и общий портфель проектов |

## Что уже работает в alpha

- Несколько проектов с отдельными SQLite-базами и общей локальной панелью.
- Чтение текстовых PDF, DOCX, XLSX/XLSM, CSV/TSV, UTF-8 TXT/MD.
- Текстовый поиск и источник до страницы, абзаца, строки или ячейки.
- Наблюдения с исходным написанием, единицами, смыслом и версией источника.
- Сверка сопоставимых количеств, история исправлений и зависимые проверки.
- Шесть навыков: чтение проекта, сверка, график, ПОС, ППР и влияние изменений.

**0.1.0-alpha.1:** это работающая основа инструментария. Все цифры проекта
автоматически не извлекаются; расчётный график и выпуск ПОС/ППР пока описаны
методикой навыков. Подробности — в [статусе реализации](docs/STATUS.md).

## Быстрый старт на Windows

Нужны Python 3.11+ и [uv](https://docs.astral.sh/uv/).

```powershell
git clone https://github.com/proovcme/uvyazka.git
cd uvyazka
uv sync --extra all
uv run uvyazka demo
uv run uvyazka dashboard
```

Панель: http://127.0.0.1:8772. Два учебных проекта содержат синтетические
данные. Собственные документы и базы не включены в репозиторий.

## Подключение

Основной интерфейс — локальный MCP. Первая целевая среда — Codex на Windows,
далее Claude Desktop и другие совместимые клиенты. Навыки и установка
адаптируются к конкретному приложению; совместимость проверяется отдельно.

```powershell
uv run uvyazka client-config codex
```

Команда выводит фрагмент настроек текущей установки. Добавьте его в настройки
клиента, сохранив остальные серверы. Есть профили `claude-desktop` и
`gemini-cli`; совместимость с Gemini Desktop не заявляется.
Проверен stdio-протокол, установка в настольных клиентах требует отдельной приёмки.

Модель и диалог остаются в выбранном клиенте. Обязательного подключения
к API моделей или собственного сервера генерации у Увязки нет.
CAD/BIM, семантический поиск, RAG-Legion, независимая интеграция ЛЕС,
локальные модели и прямые API — дальнейшие дополнительные интеграции.
MCP-фрагменты передаются выбранному ИИ-клиенту и обрабатываются по его настройкам.

## Принципы

- Каждое значение связано с источником и его версией.
- Пропуск, ошибка извлечения и проектное расхождение имеют разные статусы.
- Полноту извлечения нужно подтверждать по документам и строкам;
  полный журнал покрытия строк пока не реализован.
- Данные разных проектов разделяются; исходные документы сохраняются.
- Общая база проекта используется всеми клиентами и панелью.

## Проверка разработки

```powershell
uv sync --extra all
uv run python -m unittest discover -s tests -v
uv run python tools/validate_package.py
uv build
```

Все тестовые источники создаются синтетически во временных папках.
CI задан для Windows/Linux, Python 3.11/3.12.
