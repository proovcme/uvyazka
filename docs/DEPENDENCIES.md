# Зависимости и происхождение

Ядро использует стандартную библиотеку Python. Дополнительные зависимости
объявлены в `pyproject.toml`, конкретные версии фиксируются в `uv.lock`.

| Компонент | Использование |
|---|---|
| MCP Python SDK | Локальный stdio-сервер и протокольные проверки |
| PyMuPDF | Чтение текста PDF, изображение страницы для сверки |
| python-docx | Абзацы и таблицы DOCX |
| openpyxl | Чтение ячеек XLSX/XLSM без исполнения формул и макросов |
| xlrd (BSD) | Старый XLS: сохранённые значения, типы, форматы и объединения; выражения формул недоступны |

Пакет не содержит исходного кода RAG-Legion или ЛЕС. Адаптеры к ним пока
не реализованы. Идеи кеширования, адресного чтения и журналирования
реализованы в собственных модулях; внешние проекты сохраняют самостоятельность.

У зависимостей действуют собственные лицензии. В частности, метаданные
PyMuPDF указывают двойное лицензирование: GNU AGPL 3.0 либо коммерческая
лицензия Artifex. Публичность репозитория не меняет условия зависимостей.
Собственный код, документация и навыки Увязки — [Apache-2.0](../LICENSE),
кроме компонентов с отдельно указанными условиями. [NOTICE](../NOTICE)
фиксирует границы лицензии и отсылки к сторонним уведомлениям.
Отдельное приложение `integrations/cad-viewer` остаётся GPL-3.0-or-later;
его условия и лицензии зависимостей не заменяются Apache-2.0.

Карточки ТТК содержат только названия, происхождение и аннотации применимости;
полные тексты каталога не включены. Реальные проекты, базы, кеши и частные
конфигурации в распространяемый пакет не входят.

## Перенос IFCCS

Автор разрешил включить компоненты своего IFCCS в Увязку.
Обновление от 16 октября 2026: planner 0.5.0, simulation 0.1.1.
Перенесены доменные модули расчёта, импорта, авторинга, федерации и стадий;
интерфейс Three.js адаптирован к Увязке. Полный список исходных модулей и
SHA-256 снимка перед адаптацией — [ifccs-source.json](ifccs-source.json).
Сервер IFCCS и его MCP SDK 2.x не переносились: инструменты работают через
существующий MCP SDK 1.x Увязки.

В 0.3.0-alpha.2 включены исходники rvt-rs 0.4.0, commit
120e2f9ffa8422ba437102c8d300b7e902cdde80, под Apache-2.0, с LICENSE и NOTICE.
Файлы и SHA-256 перечислены в integrations/rvt-rs/UVYAZKA-SOURCE.json;
локальная доработка `uvyazka-native-mep-v1` перечислена в `local_patches`.
Для изменённых файлов сохранены `upstream_sha256` и фактический `sha256`;
это доработанная копия закреплённого upstream, а не неизменённый релиз.
Поставляется выбранный набор исходников для сборки, без моделей и бинарников.
Также перенесён reader стадий из IFCCS, добавлен собственный браузерный мост.
Сборка CLI выполняется локально по Cargo.lock; установка из Python wheel
не устанавливает Rust или нативные инструменты автоматически.
[Состав и сборка](../integrations/README.md).

Исходные проекты, IFC/RVT-модели, рабочие прогоны и окружения IFCCS
не переносились. Тестовые IFC генерируются программно.

| Дополнение | Условие |
|---|---|
| Three.js | MIT; текст лицензии рядом с собранным просмотрщиком и исходниками web |
| IfcOpenShell | Опциональный IFC-импорт; собственные условия LGPL-3.0-or-later |
| NumPy | Опциональный IFC-импорт; собственные условия BSD-3-Clause и включённых компонентов |
| Pillow, ezdxf, Pydantic | Опциональные рендер, DXF и типизированный авторинг; собственные лицензии пакетов |
| Vite, TypeScript, esbuild, типы Three | Инструменты сборки, конкретные версии в web/package-lock.json |

Условия прямых и транзитивных пакетов нужно учитывать при распространении.
Перенос авторского кода не меняет условия включённых сторонних компонентов.

## Демонстрационные материалы

`docs/assets/construction.gif` — GIF из авторского IFCCS 0.4
(`duplex-packages-v04.gif`), показывающий строительные пакеты.
Использован открытый образец **BSI (2020) "Duplex Apartment Test Files,"
buildingSMART International**, из [Community Sample Test Files](https://github.com/buildingsmart-community/Community-Sample-Test-Files).
Условия исходного образца: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
В GIF изменены представление, цвета и состояние элементов для демонстрации.
Сам IFC в репозиторий не включён. Это иллюстрация 0.4, не запись всех функций 0.5.

Статическое демо locia.work/uvyazka включает опубликованные данные **BSI (2020)
"Medical-Dental Test Files," buildingSMART International**, из
[Community Sample Test Files](https://github.com/buildingsmart-community/Community-Sample-Test-Files/tree/7ddf57a201f88a0c213d5322b02ed15e94a60a40/IFC%202.3.0.1%20%28IFC%202x3%29/Medical-Dental%20Clinic),
CC BY 4.0: архитектура, ОВ и ЭОМ. Изменения: триангуляция IFC в ModelPackage,
отдельные измерения геометрии и федерация с идентификаторами источников.
Пример RVT RE1-Mechanical взят из
[Drshelden/IFC-ECS](https://github.com/Drshelden/IFC-ECS/tree/9e8b37175a0fba1397f7011aeee917fe52de7623),
MIT, Copyright (c) 2026 Drshelden. Публикуется неизменённый RVT и его MIT LICENSE;
результат экспериментального чтения не равен полной модели Revit.
Фиксированные URL, SHA-256 и размеры: `tools/public-demo-sources.json`.
22 условных элемента АР/ОВ остаются дополнительным примером. Файлов заказчика,
проектной базы и доступа к локальным MCP в публичном демо нет.

## Браузерная обработка

web-ifc 0.0.78 и Pyodide 314.0.7 зафиксированы в web/package-lock.json.
WASM, Python-ядро и лицензии раздаются с того же сайта; CDN и API моделей
не используются. [Происхождение runtime](../integrations/browser-runtime/README.md).
Исходники собственных workers, IFC-адаптера и RVT-моста включены в sdist.

## Выпуск спецификаций

Браузерный PDF: jsPDF 4.2.1 (MIT), закреплён в web/package-lock.json.
OOXML XLSX: собственный минимальный писатель без формул/макросов,
ZIP — fflate 0.8.3 (MIT). Новые прямые и включённые опциональные зависимости
и их upstream license notices: `web/public/SPECIFICATION-LICENSES.txt`.
Noto Sans — SIL OFL, URL и SHA-256 в `web/assets/FONT-PROVENANCE.json`,
условия — `web/assets/OFL.txt`. Шрифт встраивается в PDF и поставляется со сборкой;
данные модели и экспорт не отправляются на внешний сервис.
