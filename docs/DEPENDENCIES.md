# Зависимости и происхождение

Ядро использует стандартную библиотеку Python. Дополнительные зависимости
объявлены в `pyproject.toml`, конкретные версии фиксируются в `uv.lock`.

| Компонент | Использование |
|---|---|
| MCP Python SDK | Локальный stdio-сервер и протокольные проверки |
| PyMuPDF | Чтение текста PDF, изображение страницы для сверки |
| python-docx | Абзацы и таблицы DOCX |
| openpyxl | Чтение ячеек XLSX/XLSM без исполнения формул и макросов |

Пакет не содержит исходного кода RAG-Legion или ЛЕС. Адаптеры к ним пока
не реализованы. Идеи кеширования, адресного чтения и журналирования
реализованы в собственных модулях; внешние проекты сохраняют самостоятельность.

У зависимостей действуют собственные лицензии. В частности, метаданные
PyMuPDF указывают двойное лицензирование: GNU AGPL 3.0 либо коммерческая
лицензия Artifex. Публичность репозитория не меняет условия зависимостей.
Лицензия на распространение собственного кода Увязки пока не выбрана;
не следует считать весь набор автоматически лицензированным под MIT.

Карточки ТТК содержат только названия, происхождение и аннотации применимости;
полные тексты каталога не включены. Реальные проекты, базы, кеши и частные
конфигурации в распространяемый пакет не входят.
