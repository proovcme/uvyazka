# Открытие источника из LES

Кандидат интеграции, рабочая установка не переключается автоматически.
LES импортирует неизменяемый снимок `UvyazkaModelData` через локальные
`/api/models/datasets`, `/api/models/query`, `/api/models/object`. Чтение исходника
и снимок создаются в Увязке. LES не копирует CAD/BIM-декодеры и не меняет оригинал.

Вьювер после совместимой сборки публикует `/simulation/les-capabilities.json`
с контрактом `uvyazka.les-viewer.v1`. Источник из LES открывается по параметрам
`project`, `les_dataset`, `les_object`, `les_sha256`. Параметры захватываются до
восстановления рабочего места и нормализации URL; произвольные пути не принимаются.

`web/src/les-source.ts` дочитывает свойства через обычный API, проверяет SHA
оригинала и ID объекта, выводит свойства в безопасном текстовом представлении.
Большие целые свойства отображаются исходными цифрами, null отличается от нуля.
Полнота чтения/инженерное утверждение из наличия свойств не следуют.
Подсветка допускается только для однозначного native ID в той же редакции и проекте.
Нет однозначной геометрии — остаются свойства и объяснение, другой объект не выбран.

Приёмник нужно поставлять вместе с его маркером возможностей. Старый установленный
вьювер не становится совместимым от одного изменения исходников. До обновления
LES предлагает установить/обновить Увязку через официальную страницу GitHub Releases.
Установщик не скачивается и не запускается скрыто. Прямое чтение всех вариантов
DWG/RVT и сквозная приёмка установленной пары этим контрактом не подтверждаются.
