# Данные моделей для человека и ИИ

MCP и локальный HTTP API читают одни неизменяемые снимки в SQLite выбранного
проекта. Оригиналы не редактируются. Чтение параметров не требует конверсии
геометрии, API языковой модели, установленного Revit или AutoCAD.

## Форматы и границы

| Формат | Локальный читатель | Что сохраняется | Ограничение |
|---|---|---|---|
| RVT | rvt-rs + native metadata reader | Поддержанные экземпляры, HostObj и наследники, MEP, типы, уровни, системы, определения видов и спецификаций; ElementId, доступный UniqueId, ссылки на исходные записи | Выбранные классы и бюджеты; сохранённые поля не являются вычисленным результатом Revit. Все классы/версии не гарантируются |
| IFC | IfcOpenShell | Продукты, типы, системы, этажи, отношения, собственные Pset/количества, GlobalId/STEP ID и определения единиц | Без тесселяции и проверки геометрии; свойства типа не подмешиваются экземпляру. Tag не назначается Revit ID |
| DWG | LibreDWG/WASM, отдельный Node-процесс GPL | Декодированные сущности, handles, слои, определения блоков, вставки, тексты и параметры листов | Нет AutoCAD, открытия xref и гарантии чтения proxy/пользовательских объектов или вычисленных CAD-таблиц |
| DXF | ezdxf | Сущности в блоках, слои, вставки с атрибутами и параметры листов | Вставка и определение блока различаются; содержимое xref не раскрывается, оформленные листы не рендерятся |
| NWD/NWC | Независимый native Navis reader | Логическое дерево, собственные декодированные свойства, родительские ссылки и явные нативные ID | Частичное чтение страниц свойств. Геометрия, сохранённые ракурсы, коллизии и TimeLiner не входят в этот профиль |
| Сцена вьювера | Сохранённый ModelPackage | Элементы/свойства, уровни, системы и отношения производной сцены | `original_file_reopened=false`: оригинал не проверялся; фрагменты и узлы не являются автоматически количеством оборудования |

Каждый ответ имеет `coverage`, источник с SHA-256 и читателя. `partial` —
граница извлечения, а не число ошибок проекта. Пустой раздел не доказывает
отсутствия объектов в исходнике. Единицы остаются исходными; преобразование
и инженерное толкование выполняются отдельно. У NWD/NWC наследуемые свойства
не копируются всем потомкам: для наследования явно проходите `parent`.
Буферы сеток не возвращаются; сохранённые координаты CAD-примитивов могут
оставаться среди их исходных полей. Они не являются пересчитанными объёмами.

## Настройка из checkout

```powershell
pip install -e ".[mcp,ifc,authoring]"
python tools/setup_rvt.py
npm ci --prefix integrations/cad-viewer
python tools/setup_model_readers.py --nwd
```

Для Rust нужны нативные инструменты C/C++; для CAD — Node.js 22+.
`model_reader_status` показывает фактическую доступность. DWG-компонент
поставляется отдельно по GPL-3.0-or-later, Apache-ядро обменивается с ним JSON
через процесс. Настройки путей к читателям (`UVYAZKA_CAD_READER`,
`UVYAZKA_NWD_READER`) задаются локально, не через HTTP или входной документ.
Wheel без checkout не содержит Node/Rust runtime: используйте исходники или
отдельно подготовленные локальные читатели.

## Работа через MCP

1. Выберите `project_id`; зарегистрируйте папку и выполните `scan`.
   `find_documents` возвращает DOC-ID. Файл может иметь статус неподдержанного
   **текстового** извлечения: для модели есть отдельный читатель.
2. Вызовите `list_model_data` и проверьте пригодность существующих снимков.
3. `read_model_data(project_id, request_id, doc_id=...)` читает оригинал;
   вместо DOC-ID можно передать **только** `scene_id` сохранённой сцены этого
   проекта. Снимок становится общим для человека и клиента MCP.
4. `query_model_data` возвращает короткий список объектов; `get_model_object`
   читает поля по `object_id` и `json_path`, с продолжением `next_offset`.
   В навигации длинные отчёты явно сокращены; полная версия доступна через
   `get_model_object(object_id="@dataset", json_path=["coverage"])`.
5. Выводы сохраняйте отдельно через `save_structure_analysis` с
   `table_id=null`, `related_sources` (DOC-ID/SHA/причина) и адресами
   dataset_id/object_id/JSON-пути в `data`. Для производной сцены нужен
   доступный зарегистрированный оригинал; сама сцена не заменяет источник.
   `record_observations` требует проиндексированного текста и не принимает
   нативное поле модели как вымышленную страницу. Сверяйте единицы и связи.

Разделы: `elements`, `types`, `systems`, `levels`, `layers`, `blocks`,
`layouts`, `views`, `schedules`, `relationships`.
Поиск `query` — подстрока имени/класса/нативного ID. `native_id` — точный
исходный ID или явный идентификатор, включая Revit ElementId. Одинаковые ID
в разных областях не объединяются: детали адресуются `object_id`.

Синтетический фильтр:

```json
{"filters":[{"path":["properties","power"],"op":"eq","value":0}]}
```

Путь относится к возвращаемой записи; сначала прочитайте пример её полей.
Операции: `eq` (точный тип и значение), `contains` (строка), `exists`
(булево наличие пути), `gt`/`lt` (числа без пересчёта единиц). Null, отсутствие,
пустая строка и ноль различаются. Идентификаторы большого размера храните
строками. Переходите по `next_cursor`, даже если текущая порция пуста;
курсор привязан к снимку и условиям поиска. Максимум 100 результатов и
2000 просмотренных кандидатов за запрос; фильтры не делают полный проход
файла заново.

У RVT `evidence.extraction_id/record_id` ведут к `get_rvt_record` для графа,
параметров и определений таблиц. Профиль `objects` выбирает поддержанные
корневые классы физических объектов и типов, `views` — виды/таблицы/размещения.
Неразобранные записи остаются с `native_status` и диагностикой.

## Версии и свежесть

Снимок адресуется DOC-ID, SHA исходника, версией контракта и отпечатком
читателя. Повторный вызов с теми же данными использует кеш. Изменение источника
или читателя создаёт новый снимок; старый остаётся. Один `request_id` повторяет
свой прежний результат — после изменения используйте новый ID.

Быстрый ответ проверяет размер/время исходника, что не доказывает неизменность
байтов. `get_model_object(verify_source=true)` проверяет SHA относительно
выбранного снимка. `current_registered_version=null` означает, что инвентаризация
ещё не хешировала бинарный файл; SHA самого снимка всё равно вычислен.
Успешное явное чтение оригинала фиксирует отложенный SHA в инвентаре;
последующие сканирования сохраняют и перепроверяют такой источник.
Принятая инженерная ревизия и утверждение результата здесь не назначаются.

Извлечение синхронное и ограниченное: 500000 объектов, 4 МиБ на объект,
128 МиБ сохранённых метаданных; нативные читатели имеют дополнительные
бюджеты/таймауты. Отказ бюджета не публикует обрезанный «успешный» снимок.
Частичный результат нативного читателя сохраняет свои ограничения.

## Локальный HTTP API

Запустите `uvyazka serve` и используйте его адрес loopback.

| Метод | Маршрут | Содержание |
|---|---|---|
| GET | `/api/models/status` | Читатели и токен текущей локальной сессии |
| POST | `/api/models/read?project_id=...` | JSON: `request_id`, `doc_id` **или** `scene_id` |
| GET | `/api/models/datasets?project_id=...` | Снимки; `offset`, `limit` |
| GET | `/api/models/query?project_id=...&dataset_id=...` | `section`, `q`, `native_id`, JSON `filters`, `cursor`, `limit` |
| GET | `/api/models/object?project_id=...&dataset_id=...&object_id=...` | JSON `json_path`, `offset`, `max_chars`, `verify_source=1` |

POST требует `Content-Type: application/json`, `X-Uvyazka-Token` из status;
при наличии Origin он должен совпадать с loopback-адресом. Host также проверяется.
Произвольные пути, исполняемые команды и URL не принимаются. Это локальный
API общего ядра; публичное статическое демо его не предоставляет и файлы
для такого чтения на VPS не загружает.

## Проверка

`tests/test_model_data.py` проверяет сохранение/возобновление, версии,
межпроектные границы, типы/неизвестные значения, длинные ID, продолжение
поиска, дубли, изменение источника, сцены и защиту HTTP. Дополнительные
синтетические проверки IFC/DXF выполняются при наличии optional-пакетов.
Протокольные тесты MCP проверяют регистрацию без обязательных BIM-зависимостей.
Это проверка контрактов; полное соответствие выдаче Revit/AutoCAD/Navisworks
для произвольной модели не утверждается.
