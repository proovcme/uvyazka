# Поиск норм без модели

В локальной панели открыт раздел **«Поиск норм»**. Это интерфейс SP MCP, доступный
через защищённый loopback-прокси «Увязки». Копия нормативной базы в проекте не создаётся.

## Запуск

Запустите SP MCP с веб-интерфейсом:

```bash
uvx --from git+https://github.com/proovcme/sp-mcp.git@v0.2.0 sp-mcp web
```

Откройте панель «Увязки» и выберите «Поиск норм». По умолчанию сервер ожидается
на `http://127.0.0.1:8767`. Для другого локального порта установите `UVYAZKA_SP_URL`.
Допускается только loopback-адрес; произвольные внешние прокси и перенаправления запрещены.
Если у SP MCP включён Bearer-токен, задайте `UVYAZKA_SP_TOKEN` в окружении «Увязки».
Токен сервера не передаётся в браузер или URL.

## Возможности

- Поиск по обозначению, названию и сохранённым фрагментам.
- По умолчанию используются русские словоформы, BM25, близкие написания и словарь инженерных понятий.
  Модель не запускается; LLM и API-ключи не нужны.
- Просмотр документа, ссылочных и сохранённых редакций, пунктов, таблиц и проверок актуальности.
- Необязательные локальные эмбеддинги настраиваются отдельно на стороне SP MCP.
- Нормативные файлы, извлечения и индексы остаются в общем хранилище SP MCP, которым пользуется и его MCP.

## Связь с проектом

1. Найдите и откройте норматив, выполните проверку конкретной редакции.
2. На вкладке «Увязка» выберите проект и его зарегистрированный исходный документ.
3. При необходимости укажите пункт норматива. Подготовьте связь и проверьте её состав.
4. Сохраните основание. Для обновления существующей связи нужна причина изменения.

SP MCP готовит пакет с источником норматива и результатом проверки. «Увязка» сохраняет его
через собственный `StructureAnalysis`: проверяет проект, фактический SHA-256 исходника и ревизию анализа.
Прямой записи внешнего сервиса в SQLite проекта нет. Источник проекта и нормативный источник — разные связи.
Сохранение не утверждает применимость требования и не означает инженерного принятия.

Все запросы из встроенной панели проходят штатные проверки Host/Origin и токена «Увязки».
Загрузка кода интерфейса и API нормативов ограничены явно перечисленными маршрутами.
Если SP MCP не запущен, панель показывает действие для подключения, а не пустую выдачу.
