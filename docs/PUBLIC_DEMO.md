# Статическое демо на locia.work

[Открыть демо](https://locia.work/uvyazka/).

Это отдельная сборка того же вьювера: готовые JSON/CSV и бинарная геометрия
читаются со статического сайта. Сервер Увязки, база проекта, MCP и ИИ-клиент
для просмотра не нужны. Загрузки пользовательских файлов нет.

Данные создаёт `tools/build_public_demo.py`: 22 учебных элемента архитектуры
и вентиляции объединяются в сводку, для них рассчитываются два сценария.
Все размеры, технологии и выработки учебные. Выдержки бетона по 28 суток —
явные допущения. 143 операции не означают полноту реального ПОС или ППР.
Результат воспроизводим при тех же версиях кода и зависимостей.

## Сборка

Установите Python 3.11+, uv и Node.js 22.12+.
В корне репозитория:

```powershell
uv sync --extra all --extra authoring
cd web
npm ci
cd ..
uv run python tools/build_demo_site.py
```

Результат: `.uvyazka-build/public-site/uvyazka/`.
Для локального просмотра запустите
`uv run python -m http.server 8774 --directory .uvyazka-build/public-site`
и откройте `http://127.0.0.1:8774/uvyazka/`.
В каталог публикации должны попасть только index.html, assets,
THREE-LICENSE.txt и demo; служебный соседний synthetic-cache не публикуется.

Основная локальная сборка остаётся отдельной: `npm run build` в web.
Она использует `/simulation/` и локальный API выбранного проекта.

## Публикация

Содержимое собранной папки можно обслуживать статическим сервером в `/uvyazka/`.
Все зависимости включены в сборку, CDN не используется. Для CSP нужны
script-src 'self', connect-src 'self', img-src 'self' data: и
style-src 'self' 'unsafe-inline' для вычисляемых полос графика.
Не публикуйте локальную базу или порт панели вместо статической сборки.
На locia.work демо развёрнуто отдельно от основного приложения сайта.
