# Увязка 0.4.0-alpha.2

Обновление полного настольного комплекта для Windows x64 и веб-демо.
База проекта остаётся общей для локальной панели и MCP-клиентов.

## Изменения после alpha.1

- Текущие независимые читатели RVT/NWD/NWC и смешанная сцена с IFC;
  экспериментальный прямой режим сохранённой графики RVT.
- Пакетная отрисовка, кеш повторного открытия RVT, очередь файлов,
  восстановление сеанса и перенос рабочего места через `.uvz`.
- Спецификации, исходные условия таблиц RVT, категории и параметры;
  фильтры и шаблоны с сохранением привязки к версии источника.
- Общие инструменты чтения данных моделей через MCP и локальный API,
  инструкции для модели в навыке чтения проекта.
- Понятные сообщения во вьювере и панели проекта. Внутренние ошибки, хеши
  и служебные поля доступны в свёрнутой диагностике. Revit ID, IFC GlobalId,
  единицы, инженерные параметры и копирование исходных значений сохранены.
- Фильтры понимают переведённые названия категорий. Неоднозначное название
  требует уточнения; условие наличия значения отключает ненужный порог.

## Поставка

`uvyazka_0.4.0-alpha.2_x64-setup.exe` — Windows x64, комплектное ядро,
вьювер, MCP, навыки и локальная панель. Python, Node.js и Rust пользователю
не требуются. WebView2 необходим для настольного интерфейса.

Отдельно доступны Python wheel, исходный архив, соответствующие исходники
зависимостей, уведомления о лицензиях и контрольные суммы.

Обновления Tauri подписаны Ed25519. Сертификата издателя Windows Authenticode
у этого выпуска нет. [Установка, MCP и обновления](DESKTOP.md).

## Проверка и границы

Изменения интерфейса прошли 232 веб-теста и 34 профильных Python-теста;
полный CI исходников проверяет ядро, вьювер, браузерные вычисления и читатели.
Это проверки реализации, а не подтверждение инженерной точности на всех проектах.
Состав MCP-инструментов замороженного ядра сравнивается с исходниками.

RVT/NWD/NWC остаются экспериментальными: прочитанная часть не подтверждает
полноту геометрии, систем, видов и спецификаций. Непрочитанная таблица
не считается пустой. Формулы и условия исходной спецификации Revit
воспроизводятся лишь в поддержанной части. Экспорт обратно в RVT отсутствует.
У веб-демо файлы обрабатываются в браузере; общая SQLite доступна локально.
