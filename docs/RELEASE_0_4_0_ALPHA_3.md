# Увязка 0.4.0-alpha.3

Обновление настольного комплекта Windows x64, MCP и веб-вьювера.

## Изменения после alpha.2

- Пространственный индекс для выбора исходных сеток и линий. Сохраняются
  точные ID, грани и точки замера; видимость и сечения учитываются при выборе.
- Смена выделения и подсветки обновляет только затронутые элементы.
  Поиск повторно использует общие группы свойств внутри ревизии.
- Сборка сводной сцены без повторного вычисления преобразования каждой вершины.
- Переносимые проекты `.uvz` версии 2: совместное хранение неизменяемых
  свойств и строк без удаления данных. Геометрия хранится отдельно;
  чтение архивов версии 1 сохранено. Старым приложениям для нового архива
  потребуется обновление.
- Этапы подготовки и открытия архива, отмена обработки до применения результата.
- Общий движок таблиц для MCP и интерфейса, включённый runtime в настольной сборке:
  таблицы по параметрам, поддержанные исходные спецификации RVT и шаблон ГОСТ.
  Результат сохраняет ссылки на ревизию и исходные элементы.

## Проверка и ограничения

Регрессии проверяют выбор и замеры по оригинальным сеткам, видимость,
отсечение, отмену worker, неизменность координат, значения свойств,
совместимость архивов и общий расчёт таблиц. Браузерная проверка дополняет
модульные тесты; она не подтверждает все версии и варианты исходных форматов.

RVT/NWD/NWC остаются экспериментальными. Это обновление отзывчивости вьювера
не устраняет все ограничения и длительные операции декодеров. Частичная
геометрия, непрочитанные системы, виды и таблицы явно отмечаются.
Непрочитанные данные не считаются отсутствующими или нулевыми.
