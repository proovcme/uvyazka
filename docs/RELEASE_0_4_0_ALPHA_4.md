# Увязка 0.4.0-alpha.4

Обновление настольного комплекта Windows x64, MCP и веб-вьювера.

## Изменения после alpha.3

- Читатель RVT обновлён до rvt-rs 0.11.0. Браузерный и нативный адаптеры перенесены на новый API; сохранены наши проекции инженерных систем, роли базового оборудования, материалы и происхождение параметров. Новые кеши не подменяют результат старым чтением.
- **Сохранение и экспорт → Экспорт IFC**: вся прочитанная сцена или видимые элементы, текущие размещения, метры, треугольные поверхности и линии, цвета, уровни, исходные ID и свойства. Есть этапы, отмена и повторная ссылка скачивания.
- Длинные Revit ID остаются строками. Неизвестное значение, ноль и `false` различаются. Длинные тексты и JSON сохраняются частями с явным правилом восстановления.
- Окно «Рабочее место» переименовано в **Сохранение и экспорт**. Кнопка **Открыть файл** открывает источник вместо текущего состава; **Добавить модель** добавляет его к сцене.

## Проверка и ограничения

Проверены сборки WASM и нативных инструментов, синтетические регрессии, повторная сверка систем RE1 Mechanical/Plumbing/Electrical с открытыми авторскими IFC, оба режима RVT через интерфейс и скачивание IFC. Независимая проверка экспорта использует IfcOpenShell, схему IFC4 и EXPRESS, контролирует размещения, линии, цвета, значения и идентификаторы.

Экспорт — производная координационная модель с объектами `IfcBuildingElementProxy`, а не восстановление параметрической модели Revit. Непрочитанные части исходника, листы, формулы спецификаций и семейства не воссоздаются. Сечения и объекты симуляции в файл не входят; выбранные тела выгружаются целиком. Прочитанные количества сохраняются как данные источника без утверждения, членство в системе не доказывает подключение портов. Бюджет операции — 512 МиБ; при превышении выдаётся ошибка без успешного частичного файла.

RVT/NWD/NWC остаются экспериментальными. Проверка отдельных файлов не подтверждает все версии и категории. Ускорение NWD и подключение нативной сцены к настольному вьюверу не заявляются частью этого выпуска.
