# План разработки

1. **Переносимый пакет.** Контракты данных и инструментов, локальный MCP,
   профили установки и навыки. Первая приёмка — Codex на Windows.
2. **Память проекта.** Реестр, версии, чтение документов, кеш, таблицы,
   покрытие обработки и продолжение долгих заданий.
3. **Сверка.** Сущности, наименования, свойства, единицы, количества,
   подтверждение источников и журнал исправлений.
4. **Другие клиенты и интеграции.** Проверка настольных клиентов,
   адаптеры CAD/BIM и внешних систем, дополнительные режимы поиска и моделей.
5. **Планирование.** Работы, объёмы, ресурсы, календари, зависимости
   и проверка реализуемости графика.
6. **ПОС и ППР.** Подготовка документов по проверенной базе и расчётам,
   согласованность текста, таблиц и графики.

Для каждого этапа отдельно фиксируются готовый код, автоматические проверки
и проверенный пользовательский сценарий. Тестовые комплекты — синтетические;
качество на реальном проекте проверяется локально.
