# План разработки

1. **Основа — реализована в alpha.** Python-пакет, локальный MCP, шесть
   навыков, отдельные базы проектов, приём и поиск текста, наблюдения,
   исправления, сравнение и панель. Протокол проверяется автоматически;
   установка в настольных клиентах остаётся отдельной приёмкой.
2. **Полнота памяти.** OCR и старые Office, извлечение всех групп показателей,
   журнал по каждой строке, продолжение долгих заданий, принятые значения
   и контроль ревизий.
3. **Сквозная сверка.** Разрешение сущностей и наименований,
   проект → спецификация → ВОР → смета, технические и финансовые основания,
   покрытие, решения инженера и влияние изменений.
4. **Другие клиенты и интеграции.** Проверка настольных клиентов,
   адаптеры CAD/BIM, выборочное переиспользование RAG-Legion,
   независимая интеграция ЛЕС, дополнительные режимы поиска и моделей.
5. **Планирование.** Работы, объёмы, ресурсы, календари, зависимости
   и проверка реализуемости графика.
6. **ПОС и ППР.** Библиотека технологических решений с проверкой применимости,
   адаптация карт, расчёты, согласованность текста, таблиц и графики.

Для каждого этапа отдельно фиксируются готовый код, автоматические проверки
и проверенный пользовательский сценарий. Тестовые комплекты — синтетические;
качество на реальном проекте проверяется локально.
