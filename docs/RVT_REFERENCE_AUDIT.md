# Независимая сверка формы RVT

Прогон 29.10.2026 сравнивает оба маршрута RVT с отдельно опубликованными
авторскими IFC из открытого [RE1 / IFC-ECS](https://github.com/Drshelden/IFC-ECS/tree/9e8b37175a0fba1397f7011aeee917fe52de7623/data/RE1).
Это не сравнение конвертера с его собственным экспортом. Лицензия корпуса — MIT;
размеры, адреса загрузки и SHA-256 зафиксированы в
[манифесте](../tools/browser-fixtures.json). Частные модели в отчёт не входят.

## Метод

Пара файлов выбирается явно. Сопоставляются только однозначные Revit ElementId:
один ID с каждой стороны. Названия и близость координат не используются.
Равенство ревизий RVT и авторского IFC независимо не подтверждено, поэтому
различие ещё не устанавливает виновника.

Для пары с треугольной геометрией проверяются мировые габариты и расстояние
выборки вершин до всех треугольников второй поверхности в обоих направлениях.
Начало отсчёта добавляется один раз; подгонки положения нет. До 32
детерминированных образцов с каждой стороны — диагностическая выборка,
а не полное расстояние Хаусдорфа, проверка топологии или валидности тела.
Порог **1 см** выбран для поиска заметных различий. Это **не** нормативный
допуск, точность инструмента или критерий приёмки проекта.

## Наблюдения на открытом корпусе

«Различия» — пары, где габариты либо выборочная поверхность отличаются более
чем на 1 см; «без пары» — ID только в одном прочитанном наборе. Это не количества
оборудования или ошибок проекта. Прямой режим читает владельцев графики.

| RE1 | Напрямую: сравнено / различия / без пары | Через IFC: сравнено / различия / без пары |
|---|---:|---:|
| Architecture | 71 / 5 / 1 | 72 / 12 / 0 |
| Mechanical | 74 / 0 / 0 | 74 / 0 / 0 |
| Electrical | 47 / 0 / 2 | 49 / 2 / 0 |
| Plumbing | 104 / 1 / 19 | 123 / 12 / 1 |

В Architecture есть отличия сохранённых форм семейств относительно авторского
IFC; часть общая для двух маршрутов. Маршрут через IFC дополнительно содержит
восстановленные формы стен и габаритные представления. Electrical и Plumbing
также требуют проверки отдельных форм и отсутствующих пар. Причина каждого
различия — ревизия, детализация, содержимое сохранённой графики или ошибка
читателя — этим прогоном не установлена. Формы автоматически не исправлялись.

Результат Mechanical означает отсутствие превышения порога в сравненной
выборке, а не доказанную полноту RVT. Отсутствие пары и недоступная геометрия
сохраняются в JSON отдельно от совпавших образцов.

## Воспроизведение

Нужны зависимости `web`, Node с `--experimental-strip-types`, собранный RVT WASM
и runtime веб-демо. Сборщик — [build_browser_runtime.py](../tools/build_browser_runtime.py),
порядок проверки — [BROWSER_VALIDATION.md](BROWSER_VALIDATION.md).

```powershell
python tools/fetch_browser_fixtures.py
node --experimental-strip-types tools/compare_rvt_reference.mjs --output .uvyazka-build/rvt-reference/report.json
```

Можно добавить `--case Mechanical` и `--runtime <каталог-runtime>`.
JSON сохраняет источники, хеши, правило сопоставления, ID, классы, названия,
происхождение формы и расстояния. Ошибка читателя даёт код завершения 2;
различия записываются как диагностический результат. Оригиналы не изменяются.
Бинарные модели и результаты остаются в игнорируемом каталоге.
Синтетические регрессии математики проверяют зеркало с тем же габаритом,
разную триангуляцию одной поверхности, вырожденные треугольники и начало отсчёта.

## Отображение качества

В свойствах различаются сохранённая графика, восстановленная форма, неизвестное
происхождение и габаритный блок. Блок не подтверждает площадь или объём.
Карточка охвата учитывает формы, требующие проверки, даже если сетка отрисована.
Эти отметки не меняют исходные параметры и не принимают инженерное решение.

Далее нужны разбор различий по исходной форме и расширение независимого корпуса.
[План доводки RVT](RVT_VIEWER_QUALITY.md) и
[проверка смешанной сцены](MIXED_SCENE_VALIDATION.md) — отдельные критерии.
