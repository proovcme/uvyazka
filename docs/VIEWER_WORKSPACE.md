# Рабочее место вьювера

Доступно во вьювере. Ревизия публичной сборки указана в `release.json`; общая SQLite используется только в подключённой локальной панели.

## Как пользоваться

- **Связи** на левой панели или вкладка справа: выбрать оборудование, перейти к системе, порту или соседнему элементу; подсветить либо изолировать прочитанную сеть. «Начало пути» фиксирует первый узел, «Путь до выбранного» ищет цепочку до второго.
- **Рабочее место** сверху: сохранить снимок, открыть его после перезапуска, создать подборку выбранных элементов или сохранить условия поиска, сравнить ревизии.
- **Ctrl / Cmd / Shift + щелчок** по элементам дерева или 3D добавляет / убирает элемент из выделения. Действия справа применяются ко всему выделению. Контекстное меню доступно на строке дерева; «↶ Видимость» отменяет последние 30 действий с видимостью и условиями фильтрации.
- **Скрыто: N** над деревом сохраняет доступ к вручную скрытым элементам после снятия выделения. «Список» показывает их независимо от поиска и фильтров; галочка возвращает отдельный элемент. «Вернуть все» восстанавливает все вручную скрытые элементы, сохраняет текст поиска, параметры и камеру. Если фильтры препятствуют возврату, их применение к 3D отключается. Разрезы остаются на месте. «Показать всю модель» выполняет полный сброс фильтров и разрезов с вписыванием модели. В DWG / DXF действует отдельная команда «Показать все слои и объекты».
- **Замер**: расстояние, проекции X/Y/Z, плоский контур или расстояние между поверхностями двух выбранных элементов. Привязки относятся к вершинам и рёбрам треугольной сетки, включая её внутренние рёбра.

## Инженерные связи

Граф различает членство в системе, владение портом, соединение портов / элементов, управление и ссылку на базовое оборудование. Названия не создают соединений. В IFC читаются `IfcRelAssignsToGroup`, `IfcRelConnectsPortToElement`, портовые `IfcRelNests`, `IfcRelConnectsPorts`, `IfcRelConnectsElements`, `IfcRelConnectsPathElements`, `IfcRelFlowControlElements`.

Браузерный RVT-адаптер использует существующую проекцию типизированных записей `RbsHvacSystem`, `RbsPipingSystem`, `RbsElectricalSystem`. Он сохраняет разницу между `network_member` и `base_equipment_reference`, адрес объекта / поля, смещение записи и хеш тела. Проверенный диапазон этой проекции — 2021 и 2024–2027; для других версий она не заявляется поддержанной. Это отдельное ограничение от общего чтения RVT.

Ссылка на базовое оборудование не является расчётом электроснабжения. Обход владения портами не проверяет внутреннюю проходимость оборудования, направление потока, электрическую непрерывность, нагрузку или защиту. Нет пути в прочитанном графе — результат «не найден в прочитанных данных». Непрочитанные участники не используются как промежуточные узлы. Частичная проекция и лимит обхода видны явно.

`get_model_network` читает граф сохранённого `ModelPackage` из базы проекта, порциями до 200 связей; необязательный путь ограничен 20 000 узлами. Браузерный пакет, открытый только локально, автоматически не становится зарегистрированной моделью MCP. Для исходного RVT нативное чтение систем также доступно через инструменты каталога RVT. Новая браузерная проекция ролей не меняет нативный конвертер.

## Хранение и общая база

Есть два уровня хранения:

1. **Снимок браузера / IndexedDB.** Именованная сцена содержит производные пакеты и бинарную геометрию, размещения, камеру, сечения, скрытые элементы, фильтры, выделение, подборки и журнал замеров. Исходные RVT/IFC не сохраняются. Браузер может удалить данные сайта, квота может закончиться; ошибка сохранения показывается пользователю. Снимок создаётся явной кнопкой, автосохранение не обещается.
2. **SQLite проекта / MCP.** Локальная панель записывает состояние через защищённый маршрут `/api/viewer/workspace`. MCP читает и меняет его через `get_viewer_workspace` и `save_viewer_workspace`. Геометрия не передаётся этим маршрутом: вьювер должен открыть тот же пакет, с совпадающими `model_id` и `source_sha256`. На статическом публичном сайте общей SQLite-базы нет.

Состояние имеет `version: 1` и точный набор полей:

```json
{
  "version": 1,
  "model_id": "<64 hex SHA-256 пакета>",
  "source_sha256": "<64 hex SHA-256 источника / сцены>",
  "hidden": [],
  "selection": [],
  "filters": {
    "query": "", "levels": [], "categories": [], "system": "",
    "parameters": [], "combine": "all", "apply3d": true, "grouping": "categories"
  },
  "view": {
    "position": [10, 10, 10], "target": [0, 0, 0], "up": [0, 1, 0],
    "planes": [], "xray": false
  },
  "measurements": [],
  "sets": []
}
```

Камера и плоскости используют систему Three.js Y-up относительно `render_origin_m` пакета; замеры — мировые координаты сцены в метрах Z-up. `levels` хранят JSON-кодированное значение `storey_id` (`null` для отсутствующего уровня), `categories` — ключи категорий вьювера. Лучше читать существующее состояние и менять необходимые поля, сохраняя остальные.

Запись требует `expected_revision` и `request_id`. Транзакция `begin immediate` проверяет ревизию: параллельный устаревший клиент получает конфликт; повтор того же запроса с тем же содержимым идемпотентен. История остаётся доступной через `get_viewer_workspace(revision=...)`. JSON ограничен 4 MiB. Host, Origin и токен защищают браузерную запись; это локальный интерфейс без многопользовательской авторизации.

Подборка содержит `id`, `name`, `model_id`, `source_sha256`, `created_at`, `kind: explicit | rule`, `ids` и для правила `filters`. Правило повторно вычисляет результаты поиска. Подборка другой модели / ревизии не применяется автоматически. Новые версии рабочего места сохраняют историю подборок. Замеры и состояние остаются наблюдениями / представлением, не утверждёнными инженерными фактами.

## Ревизии и измерения

Сравнение требует подтверждения, что это ревизии одной модели с одинаковым размещением. Используются прочитанные Revit UniqueId, IFC GlobalId, затем явный Revit ElementId. Совпадения имён и STEP-номеров не используются. Дубли и отсутствующие идентификаторы — вопросы; известные уникальные ID дают добавления, удаления и изменения параметров. Габариты сравниваются с допуском 1 мм. Это не точное сравнение геометрии: одинаковые габариты могут скрывать изменение формы, разные не отличают перенос от изменения размера.

Площадь считается для простого плоского контура с проверкой самопересечений и допуском плоскостности 1 мм. Расстояние поверхностей считается по всем парам треугольников двух элементов, включая пересечения, при бюджете 200 000 пар. Превышение бюджета возвращает ошибку без приближённого результата. Положительный зазор между поверхностями не исключает вложение одного тела в другое. Точность ограничена исходной сеткой; экспериментальная геометрия RVT не становится от этого точной.

## Проверка реализации

Регрессии используют синтетические модели: отсутствие ложных путей через членство, роли базового оборудования, неоднозначные ID, геометрические пересечения, площадь, конкурентная запись, история, HTTP-защита и обмен через MCP. Для браузерной проверки использован открытый RE1-Mechanical (Drshelden, MIT); проверка одного файла не доказывает полноту поддержки Revit.

Пункт следующего этапа — устойчивость на больших моделях и расширение покрытия форматов. Новые форматы и полная проверка подключений этой работой не заявляются.
