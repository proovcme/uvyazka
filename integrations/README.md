# RVT в составе Увязки

`rvt-rs/` — выбранные исходники rvt-rs 0.6.1, commit
`b6086d41b9758fd9b92f42f0a47b8345b9c58056`, Apache-2.0.
Сохранены [LICENSE](rvt-rs/LICENSE) и [NOTICE](rvt-rs/NOTICE).
Происхождение и SHA-256 каждого включённого файла —
[UVYAZKA-SOURCE.json](rvt-rs/UVYAZKA-SOURCE.json); перед сборкой хеши проверяются
с нормализацией CRLF → LF. Локальный патч `uvyazka-native-mep-v1` заменяет
эвристики инженерных систем чтением именованных полей и явных связей.
Он также передаёт ошибки чтения систем в диагностику IFC. Манифест хранит
список изменённых файлов, исходные `upstream_sha256` и текущие `sha256`.
Статус установленного runtime показывает базовый коммит и локальные патчи.

Патч `uvyazka-wasm-field-bounds-v1` проверяет умножение/сложение длины UTF-16
и границы среза в `walker.rs`. На wasm32 невозможная длина раньше приводила
к переполнению и `RuntimeError: unreachable` при конверсии реального RVT.
Теперь поле остаётся непрочитанными байтами; пустое булево поле также не
вызывает выход за границы. Сборка браузерного runtime проверяет хеши исходников.

Включены библиотека, CLI, необходимые данные компиляции и workspace-члены
Python/WASM. Корпус RVT/RFA/IFC, чужая Git-история, окружения и готовые
исполняемые файлы не включены. Полный набор upstream-тестов здесь не поставляется;
для него используйте исходный репозиторий.

`rvt-metadata-reader/` перенесён из авторского IFCCS: ограниченное чтение
сохранённых стадий, параметров, видов и спецификаций через тот же декодер.
Добавлен режим `--extract INPUT.rvt REQUEST.json OUTPUT`: каталог классов
и текущие нативные записи с покрытием и диагностикой. Это собственное
дополнение. [Работа с данными](../docs/RVT_DATA.md). Имя
исполняемого файла ifccs-rvt-metadata сохранено для совместимости.

`rvt-browser-bridge/` — дополнение Увязки: ввод байтов, сохранённые сетки,
диагностика, запрет выдачи пустого IFC при отсутствии геометрии. WASM подключён
к браузерной смотрелке; публикация обновлённой сборки на VPS выполняется отдельно.
[Возможности смотрелки](../docs/VIEWER.md).

## Сборка и проверка

Из корня checkout Увязки, с Rust >=1.87 и системными C/C++ build tools:

```powershell
uv run python tools/setup_rvt.py
uv run uvyazka rvt-status
```

Сборка использует Cargo.lock, устанавливает четыре бинарника в локальное
состояние Увязки и атомарно выбирает готовую версию. Существующие версии
сохраняются. Хеши бинарников проверяются при использовании. Ключи API,
Revit и каталог прежнего IFCCS не нужны. Если задан UVYAZKA_HOME, используйте
то же значение при сборке и при запуске MCP. Также есть wrapper tools/setup_rvt.ps1.

Для синтетической проверки конвертера:

```powershell
uv run python tools/setup_rvt.py --with-fixture-generator
uv run python tools/check_rvt_runtime.py
```

Установки из wheel могут использовать уже собранный runtime или явный
UVYAZKA_RVT_BIN_DIR. Для сборки из исходников нужен checkout или sdist;
Rust-исходники не дублируются в Python wheel.

Для проверки WASM-моста:

```powershell
rustup target add wasm32-unknown-unknown
cargo check --locked --manifest-path integrations/rvt-browser-bridge/Cargo.toml --target wasm32-unknown-unknown
```

Это проверка компиляции; работоспособность браузерного загрузчика проверяется
отдельно. Все зависимости сохраняют собственные лицензии.

## Экспериментальное чтение Revit 2021

Патч `uvyazka-native-2021-v1` допускает нативный граф 2021 с 32-битными ID,
сохраняя проверки обеих длин записи, счётчиков, схемы и текущей записи.
Проекция систем понимает явные обёртки `m_id.m_id` и `m_id.m_id64`;
отрицательные и выходящие за диапазон ID не становятся участниками системы.
Версия 2022 для нативного графа не включена. Для 2023–2027 сохранён прежний
допуск; поддержка отдельных классов и MEP может отличаться.

На локальном RVT 2021 проверены 17 систем без ошибок проекции, 131 запись
профиля views и 2218 записей engineering. Полный профиль all достиг бюджета
128 MiB и остался partial. В IFC: 922 трубы с сохранённой графической сеткой,
889 фитингов с габаритными оболочками; уровни не восстановлены. Это проверка
одной модели, не сертификация формата. Исходник и извлечённые данные приватны
и в репозиторий не входят. Публичная регрессия трёх RE1 Revit 2025 повторно
прошла после обновления: 5/8/13 систем и совпадение явных принадлежностей.
