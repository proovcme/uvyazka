# Локальный DWG / DXF viewer

Самостоятельное браузерное приложение (GPL-3.0-or-later), встраиваемое через iframe.
Принимает `File` и возвращает статус / список слоёв через ограниченный `postMessage`.
Проверяются origin, source окна, канал и идентификатор загрузки. Файлы не отправляются на сервер.

## Сборка

Из корня репозитория: `npm --prefix integrations/cad-viewer ci`, затем
`python tools/build_cad_viewer.py`. Node.js 22+; Python 3.11+.
`sources.lock.json` фиксирует архивы исходников и их SHA-256. Сборщик скачивает
их в игнорируемый кеш, проверяет и публикует рядом с приложением.
`public/`, `dist/`, `node_modules/` генерируются и не включаются в Git.

Компоненты: MLightCAD cad-simple-viewer 1.7.6 (MIT), libredwg-converter 3.15.11
и libredwg-web 0.8.1 (GPL-3.0). Используется отдельная версия Three.js,
совместимая с CAD движком. `lodash-es` зафиксирован на 4.18.1 вместо уязвимой
транзитивной версии. Lock-файл содержит точные версии и integrity.

Архив libredwg-web содержит C/C++, JS bindings и инструкции Emscripten.
Подмодуль jsmn предоставлен отдельным архивом; распаковать его в `jsmn/`.
Архив realdwg-web содержит исходники конвертера и скрипты сборки worker.
Используемые пакеты npm содержат также JS и декларации типов.

Сейчас это просмотр чертежа, а не универсальный 3D DWG solid modeller.
Текст использует свободный Noto Sans как замену отсутствующих шрифтов;
точность SHX, сложных объектов, внешних ссылок и листов не гарантируется.
Строительные элементы, объёмы и технология из линий автоматически не выдумываются.
Симуляция в основном приложении доступна по IFC / экспериментальному RVT.


`harden-worker.mjs` заменяет две фабрики динамического JavaScript в Emscripten
на замыкания. SHA-256 исходного worker проверяется до изменения; сборка останавливается
при другой версии. CSP не требует обычного unsafe-eval. Проверка парсера:
`python tools/fetch_cad_fixtures.py`, `node tools/check_cad_worker.mjs` из корня.
Она сравнивает полный JSON исходного и исправленного worker на четырёх DWG.

## Метаданные для локального MCP

`node read-data.mjs input.dwg output.json` — отдельный GPL-процесс поверх того
же libredwg-web. Возвращает декодированные сущности, слои, блоки, вставки,
тексты и параметры листов; xref не открывает. Python-ядро получает JSON через
процесс и сохраняет источник/поля в базе проекта. `npm ci` нужен отдельно;
файл не отправляется на сервер. Это частичный набор CAD-данных, не гарантия
восстановления сложных объектов и вычисленных таблиц.
