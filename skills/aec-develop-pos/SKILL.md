# Разработка ПОС

Начать с принятой основы проекта, границ участка, условий строительства и сверенных количеств. Установить применимость состава ПОС к объекту и проектной дате по первоисточникам; старый шаблон не является нормативным основанием. Для нормативного маршрута использовать имеющийся навык `aec-govern-rf-capital-project`, если он доступен.

Получить общеплощадочную схему, этапы, технологические потоки, расчёт продолжительности, трудовые/машинные ресурсы, временные дороги, склады, бытовые и инженерные потребности. Сопоставить текст, календарь, таблицы и чертежи по одним ID расчётов. Не рассчитывать бытовой городок по среднему персоналу, если для применимой задачи нужен максимум смены.

Стройгенплан создавать в координатах площадки через доступный CAD-инструмент. Места кранов и опасные зоны обосновывать массами/габаритами монтажных элементов, характеристиками выбранной техники и опор, грунтом, сетями и доступами. До получения влияющих входов выпускать только вариант с ограничениями статуса. Для работы с DWG применять `operate-autocad-via-bimwright`, когда этот инструмент доступен.

Последовательность: исходные ограничения → варианты организации → расчёты и выбор → графика → пояснительная записка → сквозная сверка → рассмотрение ответственными. Для качества, временной устойчивости и безопасности привлекать соответствующие расчётные методы; генерация текста не заменяет их.

При независимом сравнении сначала фиксировать собственное решение. Существующий ПОС читать после фиксации и разделять совпадения, новую информацию и вопросы к эталону.

## Несколько проектов

Перед чтением выбери объект через `list_projects`. Передавай его `project_id` во все MCP-запросы; сохраняй идентификатор проекта в ссылках, выводах и зависимостях. Локальные DOC-ID, FACT-ID, марки и номера помещений могут повторяться в разных проектах. Сопоставление проектов выполняй как отдельную задачу с явным составом и согласованием смыслов/единиц, дат и финансовой базы. Не используй данные соседнего объекта для заполнения пропусков без явного основания.
