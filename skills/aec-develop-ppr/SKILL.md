# Разработка ППР

Установить работу, фронт, принятую РД, условия ПОС, фактическую технику/оснастку и исполнителя. План реализации проекта и общая типовая карта не заменяют ППР на данную работу. Если существующий ППР не найден, зафиксировать поиск и отсутствие идентифицированного эталона.

При выборе типовой технологии прочитай [подбор ТТК](references/technology-cards.md).

Для каждого технологического шага указать входную готовность, действия, ресурсы, место и время, контроль, опасности/меры, результат и условие перехода. Привязать к работам графика, элементам, источникам и исполнительным записям. Сопоставить количества с проектом, ВОР и сметой по смыслу; не подменять ими фактическую технологию.

Определить требуемые расчёты по реальному процессу: временная устойчивость, крепление котлована/водозащита, опалубка, настилы/опоры, строповка, грузовые характеристики и реакции. Выполнять их специализированным методом и проверять инженером. Не назначать кран только по максимальной паспортной грузоподъёмности. Устойчивость окончательной конструкции не доказывает устойчивость каждого монтажного состояния.

Отдельно проверить зимний/летний режим и ограничения материалов/оборудования. Условия снятия временного крепления и допуска следующей операции должны быть проверяемыми. Состав и нормативную основу устанавливать для текущей работы и даты.

Выход: технологические карты, локальный график, схемы, потребность в ресурсах, план контроля и расчётные приложения в пределах имеющихся данных. Статус готовности назначать по закрытым условиям, не по наличию заполненного текста.

## Несколько проектов

Перед чтением выбери объект через `list_projects`. Передавай его `project_id` во все MCP-запросы; сохраняй идентификатор проекта в ссылках, выводах и зависимостях. Локальные DOC-ID, FACT-ID, марки и номера помещений могут повторяться в разных проектах. Сопоставление проектов выполняй как отдельную задачу с явным составом и согласованием смыслов/единиц, дат и финансовой базы. Не используй данные соседнего объекта для заполнения пропусков без явного основания.
