# Расчёты, оформление и проверка

Выбери проект через list_projects. Прочитай только нужную профильную методику
ru-aec по [маршруту](references/ru-aec-methods.md). Она помогает определить
исходные данные, физическую постановку, применимые нормы и состав выдачи.
Числовые операции и хранение выполняет MCP; чтение методики не означает
выполнение расчёта или проверку нормативного соответствия.

Для существующего расчёта прочитай оригинал через read_evidence,
read_structure_table или исходную страницу. Сверь формулу, размерности,
подстановку, режим, коэффициенты, промежуточные значения и выбранное оборудование.
Не принимай формулу из образца без проверки. Формулы Excel и сохранённые
результаты различай; пересчёт поддержанной арифметики доступен через
calculate_structure_value. Неизвестное значение не заменяй нулём.

Вызови list_engineering_methods. Для поддержанного метода передай
run_engineering_calculation точные inputs с единицами, basis и источниками
doc_id/sha256/физическая страница PDF либо явными допущениями. Для проверки
чужих итогов задай reported_results с абсолютным допуском; criteria содержат
проверенное основание применимости каждого предела. Сохраняй режимы раздельно.
Неподдержанную постановку решай доступным профильным расчётным средством и
сохраняй его исходники и выводы; не выдавай ближайший упрощённый метод за полный.

Для подготовки документа сначала прочитай engineering_document_schema.
build_engineering_document собирает PDF из точных версий расчётов и/или
векторных примитивов. Назначай реквизиты, размеры и толщины явно; для каждого
УГО передавай проверенное происхождение либо отметку проектного обозначения.
Сохраняются редактируемое описание листов и PDF. Рабочая рамка и блок реквизитов
не являются автоматически полной основной надписью СПДС. Нативный DWG/RVT
выпускается соответствующим инструментом, затем проверяется отдельно.

Для проверки оформления вызови check_engineering_document по зарегистрированному
PDF или сформированному документу. Задай физические страницы, размер листа,
рамку, область/размер шрифта и обязательные надписи с основаниями. Просмотри
конечные листы: УГО, линии, размеры, читаемость, таблицы, реквизиты, переносы и
согласованность текста с графикой. Шрифт PDF в пунктах не равен высоте прописной
буквы в миллиметрах. Сканы, неизвестные правила и непроверенные страницы остаются
непроверенными; успешные отдельные проверки не означают готовность к выпуску.

Продолжай через get_engineering_work: calculation, document, document_check.
Исправление требует expected_revision и reason, повтор запроса использует тот же
request_id. Проверяй актуальность исходников и зависимых расчётов. Итог объясняет
что посчитано/проверено, расхождения, остаток и границы применимости.

Полные поля, единицы и ограничения получай из каталога методов и схемы MCP,
чтобы работать по версии установленного сервера.
