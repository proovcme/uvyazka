# Правила сопоставления

## Соответствие позиции

Ключ: объект + зона/оси/уровень + система + марка/код + тип/материал/исполнение + назначение + роль количества + версия. Первым использовать точные шифры и характеристики, затем подтверждённые синонимы. Нечёткое сходство названий - только кандидат. Не объединять В20 с В25, DN с наружным диаметром без правила, основное и резервное оборудование, материалы разных классов/толщин.

Нормализовать алфавиты в шифрах осторожно: латинская B и кириллическая В могут быть опечаткой/вариантом кодировки, но изменение исходного шифра не выполнять. Хранить исходное имя и нормализованный поисковый вариант.

## Количественные правила

| Сверка | Правило и ограничение |
|---|---|
| План и спецификация | Считать экземпляры по ID/марке/зоне, исключая условные обозначения, легенды, подложки и повторные виды. Проверять марки без спецификации и спецификации без размещения |
| Деталь и общий расход | Объём/масса единицы x число элементов. Не умножать повторно итоговую ведомость |
| Спецификация и ВОР | Показать, какие ресурсы формируют одну работу и какие операции покрывает ресурс. Количество труб не включает автоматически испытания, изоляцию, проходки и крепления |
| ВОР и ЛСР | Читать единицу полностью: 10/100/1000 единиц; отрицательные корректировки толщины; формулы состава объёма. Нормативная строка и материал - разные записи |
| Геометрия и поставка | Явно учитывать норму расхода, припуски, отходы, укрупнение/раскрой и повторное использование. Коэффициент должен иметь основание; обратное деление показывает эффективный коэффициент, но не подтверждает его нормативность |
| Длина и штуки | Проверять длину единичного изделия. Для БР100 длина 1 м позволяет перевести шт в п.м.; для иной длины та же численность не означает ту же длину |
| Площади и слои | Повторение одной площади для трёх слоёв не означает утроение пятна покрытия. Объём слоя = площадь x толщина с одинаковыми границами |
| Экспликации | Сверять номер/назначение/этаж и метод площади. Сумма площадей помещений не обязана равняться общей площади здания без учёта принятой методики |
| Мощности | Сравнивать одинаковые виды: установленная/расчётная/разрешённая, активная/полная, рабочий/пожарный режим. Для кВт и кВА нужен подтверждённый cos phi и расчётный режим |
| Балансы воды и тепла | Сохранять вложенные показатели. ГВС, указанное «в составе общего расхода», не прибавлять к общему повторно. Проверять сутки/час/секунду и расчёт одновременности |
| Финансы | Сначала структура и объёмы, потом цены/индексы/НДС. ЛСР, ОСР и ССР - иерархия, не независимые слагаемые. Разницу из-за дат цен не считать разницей количества |
| ПОС и график | Трудоёмкость, часы в дне, рабочие дни, смены и категории персонала должны иметь общий смысл. Среднее число персонала не заменяет пик загрузки |

Для чисел с допустимым округлением хранить точность источника и правило допуска. Для целых количеств изделий и кодов обычно требуется точное совпадение. Универсальный допуск 5% запрещён. Для отрицательных и нулевых значений не считать относительную разницу делением на ноль; отсутствие значения отдельно от нуля.

## Синтетические примеры

- 0,2 в измерителе 100 m3 означает 20 m3, если совпадают сущность и вид количества.
- Одинаковое число для объёма в конструкции и поставки не подтверждает одинаковую базу.
- Ошибка чтения десятичного разделителя снимается по увеличенному оригиналу; историю исправления и зависимые сверки сохранять.

## Закрытие вопроса

Сохранить решение, полномочие/ответственного, ссылку на исправленный документ или обоснование, дату и изменённые связи. После новой ревизии повторить затронутые проверки. Нельзя закрыть вопрос одной высокой уверенностью модели или совпадением текста нескольких ответов.
